# Job: closed-deal handoff

The job in one sentence: when a deal moves to Closed won, check what the project and the first invoice need.

This file is a sample for Acme Corp, a made-up services firm. It is illustrative.

## Fields this job reads

Each field is defined in field-dictionary.md, and only there.

- HubSpot: Deal stage (dealstage)
- HubSpot: Amount (amount)
- HubSpot custom field: Contract length (contract_length)
- HubSpot custom field: Renewal date (renewal_date)
- Xero: invoice Status (Status)
- Asana: project status (current_status_update.status_type)
- The Stage definitions table

## What this job may change

Nothing. The agents in this kit only read. The Who may change it column in field-dictionary.md says which person changes each field.
