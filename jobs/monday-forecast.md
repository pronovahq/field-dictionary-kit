# Job: Monday forecast

The job in one sentence: every Monday, list the deals likely to close this month and what's blocking each one.

This file is a sample for Acme Corp, a made-up services firm. It is illustrative.

## Fields this job reads

Each field is defined in field-dictionary.md, and only there.

- HubSpot: Deal stage (dealstage)
- HubSpot: Amount (amount)
- HubSpot: Close date (closedate)
- HubSpot: Weighted amount (hs_projected_amount)
- HubSpot custom field: Deal health (deal_health)
- The Stage definitions table

## What this job may change

Nothing. This job only reads.
